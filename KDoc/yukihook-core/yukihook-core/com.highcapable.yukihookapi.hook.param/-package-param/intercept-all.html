fun Collection<Class<*>>.interceptAll(priority: YukiHookPriority = YukiHookPriority.DEFAULT, invocation: HookChain.() -> Any?): YukiHookCreator.ChainMemberHooker.Handle

Creates direct chain hooks for the static initializers of these classes.

Each class is registered independently, this operation is not atomic. Obtain every class without initializing it. An already initialized class never invokes this hook. Intercepting without HookChain.proceed skips static initialization and leaves static fields at JVM defaults.

Receiver

the classes whose static initializers will be hooked.

fun Array<Member>.interceptAll(priority: YukiHookPriority = YukiHookPriority.DEFAULT, invocation: HookChain.() -> Any? = { null }): YukiHookCreator.ChainMemberHooker.Handle

Creates a direct chain hook for methods and constructors through an Array of Member instances.

Intercepting without HookChain.proceed skips the original member. The default invocation returns null without calling it.

  • Note: YukiHookRuntime.XPOSED_82 simulates a module-local chain through a low-priority native hook. HookChain.proceed runs this runtime's remaining chain hooks and then the original member. Classic hooks and other modules are not part of this chain, later native hooks may be skipped. priority orders the local chain and does not preserve framework-wide hook ordering.

the current members to hook.
